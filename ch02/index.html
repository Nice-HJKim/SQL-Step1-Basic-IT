2.3 · SELECT 목록 구성하기

SELECT 목록 구성하기

기본 문법

SELECT 컬럼명, 계산식 AS 별칭, '문자값' AS 별칭
  FROM 테이블명;

• 컬럼·계산식·고정 문자 함께 조회

SELECT account_number,
       balance,
       balance / 10000 AS balance_10k,
       '원화 계좌' AS report_label
  FROM accounts;
출력 항목역할
account_number · balance테이블에 저장된 컬럼
balance / 10000저장된 값을 이용한 계산식
'원화 계좌'직접 지정한 고정 문자값
balance_10k · report_label결과 컬럼의 제목인 별칭
고정 문구는 조회자가 붙인 값. 이 예제의 “원화 계좌”는 통화 컬럼을 조회한 결과가 아님.
  • SELECT 목록의 순서대로 결과 컬럼 표시.
  • 출력 항목은 쉼표로 구분.
  • 원본 컬럼값은 변경되지 않음.
2.4 · 필요한 컬럼과 출력 순서 지정

필요한 컬럼과 출력 순서 지정

• 영업점의 모든 컬럼 확인

SELECT *
  FROM branches;

• 보고서에 필요한 컬럼만 지정

SELECT branch_id, branch_name, region_name
  FROM branches;
작성 방식사용 시 확인
SELECT *테이블의 컬럼 전체를 빠르게 살펴볼 때 활용
컬럼명 명시필요한 항목과 출력 순서를 명확히 지정
반복 사용하는 조회문은 필요한 컬럼을 명시. 불필요한 데이터 전달을 줄이고 결과 항목을 분명하게 관리.
  • 컬럼 순서는 SELECT 목록으로 지정.
  • 행의 출력 순서는 별개의 문제. ORDER BY가 없으면 특정 순서를 보장하지 않음.
  • 키워드 대문자, 컬럼명 소문자 등 작성 규칙을 정해 일관되게 사용.
2.5 · 별칭과 따옴표 정확하게 사용하기

별칭과 따옴표 정확하게 사용하기

기본 문법

SELECT 컬럼명 AS 별칭,
       컬럼명 AS "공백/특수문자 포함 별칭"
  FROM 테이블명;
표현의미
AS 별칭결과 제목 지정. AS 생략 가능
"계좌 잔액"공백이 포함된 별칭은 큰따옴표 사용
'계좌 잔액'작은따옴표는 문자값을 표시할 때 사용

실행 전에 예상하기

다음 두 SQL은 각각 몇 개의 컬럼을 출력할까?

• 쉼표가 빠진 SQL

SELECT branch_id branch_name
  FROM branches;

• 두 컬럼을 선택한 SQL

SELECT branch_id, branch_name
  FROM branches;
첫 SQL의 branch_name은 branch_id의 별칭으로 해석되어 결과는 1컬럼.
두 번째 SQL은 쉼표로 구분한 2컬럼. 실행 성공만으로 결과가 맞다고 판단하지 않기.
별칭은 원본 컬럼명이 아님

조회 결과의 제목만 변경. 별칭으로 원본 테이블의 컬럼명이 바뀌는 것은 아님.

2.6 · 계산식의 단위와 순서 확인하기

계산식의 단위와 순서 확인하기

기본 문법

SELECT 숫자컬럼 / 10000 AS "금액(만원)"
  FROM 테이블명;

• 잔액을 원·만원 단위로 함께 조회

SELECT account_number,
       balance AS "잔액(원)",
       balance / 10000 AS "잔액(만원)"
  FROM accounts;
✓ 숫자는 10000처럼 쉼표 없이 작성.
✓ 원래 값과 변환한 값을 함께 보며 단위 확인.

• 요구사항에 맞는 계산식 선택

“잔액에 1만원을 더한 가정 금액을 만원 단위로 표시해 주세요.”

• 괄호에 따른 계산 결과 비교

SELECT account_number,
       balance + 10000 / 10000 AS "계산A",
       (balance + 10000) / 10000 AS "계산B"
  FROM accounts;
곱셈·나눗셈을 먼저 계산. 계산A는 balance + 1, 계산B는 1만원을 더한 뒤 만원으로 환산한 값.
NULL과 산술 계산

NULL이 포함된 일반적인 산술 계산 결과는 NULL. NULL은 실제 금액 0과 구분하며, 대체값 처리는 Ch4에서 학습.

2.7 · 문자값 표시와 연결

문자값 표시와 연결

기본 문법

SELECT 문자컬럼 || '구분 문자' || 문자컬럼 AS "결과 제목"
  FROM 테이블명;

• 고정된 문자를 결과에 표시

SELECT customer_name AS "고객명",
       '고객' AS "구분"
  FROM customers;

• 고객명과 등급을 한 컬럼으로 표시

SELECT customer_name || ', ' || customer_grade AS "고객 정보"
  FROM customers;
기호역할
' '직접 표시할 문자값
" "공백·대소문자 등을 구분할 결과 제목
||문자 연결
직접 해보기: 구분 문자를 쉼표에서 /로 바꾸어 결과 비교.
문자열로 표시한 결과와 원래 컬럼의 의미를 구분.
2.8 · DISTINCT의 중복 기준 이해하기

DISTINCT의 중복 기준 이해하기

기본 문법

SELECT DISTINCT 컬럼1, 컬럼2
  FROM 테이블명;
DISTINCT는 선택한 컬럼값의 조합 전체에서 중복을 제외.
원본 행을 삭제하거나 원하는 업무 단위로 자동 집계하는 기능은 아님.

• 계좌를 보유한 고객번호 목록

SELECT DISTINCT customer_id
  FROM accounts;

• 고객번호와 계좌종류의 조합

SELECT DISTINCT customer_id, account_type
  FROM accounts;

• 고객번호와 계좌번호의 조합

SELECT DISTINCT customer_id, account_number
  FROM accounts;
SELECT 목록중복 판단 기준현재 데이터의 결과
customer_id고객번호90행
customer_id, account_type고객번호 + 계좌종류240행
customer_id, account_number고객번호 + 계좌번호250행
계좌번호는 기본키이므로 계좌별 행이 구분됨. DISTINCT를 붙여도 고객 한 명당 한 행으로 바뀌지 않음.
전체 고객 목록과 계좌를 보유한 고객 목록도 서로 다름. DISTINCT는 정렬을 보장하지 않음.
2.9 · 실행 오류와 결과 오류 찾기

실행 오류와 결과 오류 찾기

오류 메시지뿐 아니라 출력 컬럼·제목·단위가 요구사항과 맞는지도 확인.

구분확인할 내용
실행 오류컬럼명·쉼표·연산자·따옴표
결과 오류출력 항목·별칭·계산 단위·중복 기준

1. 계좌번호와 잔액의 두 배를 조회하려는 SQL

SELECT account_number, balance x 2
  FROM accounts;

2. 영업점명을 Branch Name이라는 제목으로 표시하려는 SQL

SELECT branch_name AS Branch Name
  FROM branches;

3. 고객번호와 잔액(만원)을 조회하려는 SQL

SELECT customer_no, balance / 10000 AS 잔액 만원
  FROM accounts;

4. 고객번호만 중복 없이 조회하려는 SQL

SELECT DISTINCT customer_id, account_number
  FROM accounts;
각 문항에서 의도와 다른 부분을 찾고 수정한 뒤, 바뀐 결과를 설명해보기.

업무형 실습

요구사항과 결과 예시를 보고 SQL을 직접 작성하세요. 정렬은 아직 지정하지 않으므로 캡처와 행 순서가 달라도 됨.

실습 1. 영업점 보고서

BRANCHES에서 영업점코드·영업점명·지역을 이 순서로 조회하는 SELECT문을 작성하세요.

실습 2. 계좌 잔액 보고서

ACCOUNTS에서 계좌번호·잔액(원)·잔액(만원)을 조회하세요. 금액 컬럼 제목은 각각 잔액(원), 잔액(만원)으로 지정하세요.

실습 3. 고객 표시 문구

CUSTOMERS에서 고객명과 고객등급을 /로 구분하여 한 컬럼으로 조회하세요. 결과 제목은 고객 정보로 지정하세요.

실습 4. 고객과 보유 계좌종류 구분

ACCOUNTS에서 ① 고객번호만 중복 없이 조회하는 SQL, ② 고객번호와 계좌종류의 조합을 중복 없이 조회하는 SQL을 각각 작성하세요. 두 결과의 행 수가 다른 이유를 설명하세요.

실습 5. 출력 항목과 계산 검증

ACCOUNTS에서 계좌번호·잔액·잔액에 1만원을 더한 금액을 조회하세요. 세 번째 컬럼의 제목은 가정 잔액으로 지정하세요. 원본 잔액을 변경하는 SQL은 작성하지 마세요.
