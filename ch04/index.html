  • 다중행 함수: 여러 행의 값을 처리하여 그룹마다 하나의 결과값을 반환.

4.2 · 문자 추출과 길이 확인

문자 추출과 길이 확인

기본 문법

SUBSTR(문자값, 시작 위치, 가져올 글자 수)
LENGTH(문자값)
  • SUBSTR: 지정한 위치에서 문자 일부 추출.
  • LENGTH: 문자의 글자 수 반환.

• 고객 이름의 첫 글자 추출

SELECT customer_id, customer_name,
       SUBSTR(customer_name, 1, 1) AS "첫 글자"
  FROM customers
ORDER BY customer_id;

• 고객 이름의 글자 수 확인

SELECT customer_id, customer_name,
       LENGTH(customer_name) AS "이름 길이"
  FROM customers
ORDER BY customer_id;
끝에서부터 추출하기
SUBSTR(문자값, -6)
  • 음수 시작 위치는 문자열 끝에서 계산. -6은 뒤에서 여섯 번째 위치이며, 길이를 생략하면 끝까지 추출.
글자 수와 저장 크기
  • LENGTH는 글자 수를 확인하는 함수. 저장에 사용하는 바이트 수와는 다름. 현재 실습 고객명은 모두 세 글자로 구성됨.
글자 수와 바이트 수 비교

기본 문법

LENGTH(문자값)
LENGTHB(문자값)
SELECT LENGTH('iM뱅크') AS "글자 수",
       LENGTHB('iM뱅크') AS "바이트 수"
  FROM dual;
바이트 수는 문자 집합에 따라 달라질 수 있음. 한글 한 글자를 항상 3바이트라고 단정하지 않기.
4.3 · 문자 정리와 치환

문자 정리와 치환

기본 문법

TRIM(문자값)
REPLACE(문자값, '찾을 문자', '바꿀 문자')
LOWER(문자값)

• 양끝 공백과 하이픈 제거

SELECT TRIM('  iM뱅크  ') AS "양끝 공백 제거",
       REPLACE('506-12-000001', '-', '') AS "하이픈 제거"
  FROM dual;
TRIM은 기본적으로 양끝 공백 제거. 중간 공백은 유지.
REPLACE는 일치하는 문자열 치환. 바꿀 문자를 빈 문자열로 지정하면 해당 부분 제거.

• 영문 대소문자 통일

SELECT 'User1001@Example.COM' AS "변환 전",
       LOWER('User1001@Example.COM') AS "변환 후"
  FROM dual;
LOWER는 영문 소문자 변환. 이메일 유효성 검사나 연락 가능 여부 확인을 뜻하지 않음.
4.4 · 숫자 반올림과 버림

숫자 반올림과 버림

기본 문법

ROUND(숫자, 남길 소수 자리수)
TRUNC(숫자, 남길 소수 자리수)
  • ROUND: 지정한 자리까지 남기도록 반올림.
  • TRUNC: 지정한 자리 아래의 숫자를 잘라냄.
  • 자리수 2는 소수 둘째 자리까지, 1은 소수 첫째 자리까지, 0은 정수로 표시.
DUAL 테이블이란?
  • 연산 결과나 함수 값을 확인할 수 있도록 Oracle이 제공하는 1행 1열 시스템 테이블.
  • 업무 테이블을 조회하지 않고도 FROM DUAL을 사용해 계산 결과를 한 행으로 확인 가능.

• 같은 숫자로 반올림과 버림 비교

SELECT 45.926 AS "원래 값",
       ROUND(45.926, 2) AS "반올림 결과",
       TRUNC(45.926, 2) AS "버림 결과"
  FROM dual;

• 대출원금을 억원 단위로 반올림·버림

SELECT loan_id, loan_amount,
       loan_amount / 100000000 AS "대출원금(억원)",
       ROUND(loan_amount / 100000000, 1) AS "반올림(억원)",
       TRUNC(loan_amount / 100000000, 1) AS "버림(억원)"
  FROM loans
ORDER BY loan_id;
함수 안의 계산 순서
  • ROUND(loan_amount / 100000000, 1)은 대출원금을 억원 단위로 바꾼 값을 반올림하는 식.

• 양수·음수와 정수 자리 비교

SELECT ROUND(45.926, 2)  AS "양수 반올림",
       TRUNC(45.926, 2)  AS "양수 버림",
       ROUND(-45.926, 2) AS "음수 반올림",
       TRUNC(-45.926, 2) AS "음수 버림",
       ROUND(12550, -3)  AS "천 단위 반올림",
       TRUNC(12550, -3)  AS "천 단위 버림"
  FROM dual;
✓ 자리수
  • 자리수 > 0: 소수점 아래 자리
  • 0 (또는 생략): 정수 자리
  • 자리수 < 0: 십·백·천 단위
✓ 주의
  • 예: TRUNC(-45.926, 2) → -45.92
  • 음수의 버림을 항상 더 작은 수로 처리한다고 해석하지 않기.
상품별 이자·수수료의 반올림 기준은 별도의 업무 규칙 확인.
4.5 · 현재 시각과 업무 기준일

현재 시각과 업무 기준일

기본 문법

SELECT SYSDATE
FROM dual;

• DB 기준 현재 날짜와 시간 확인

SELECT SYSDATE AS "현재일시"
  FROM dual;
  • SYSDATE: DB 서버 기준 현재 날짜와 시간 반환.
  • 화면에 날짜만 보여도 값에는 시간 정보가 포함됨.
  • 실행 시점에 따라 결과가 달라짐.
  • 클라우드 실습 환경의 서버 시간은 한국 시간과 다를 수 있음.
이 장의 날짜 계산 기준
날짜 계산 예제는 2026-03-31로 고정.
SYSDATE 예제만 실행 시점의 날짜와 시간을 표시.
날짜를 직접 지정하기
DATE '2026-03-31'
  • 지정한 날짜의 00:00을 의미함. 두 DATE 값을 뺀 결과는 일 단위이며 시간 차이가 있으면 소수도 포함됨.
표현식기준반환 자료형
SYSDATE서버의 현재 날짜·시간DATE
CURRENT_DATE세션 시간대의 현재 날짜·시간DATE
DATE '2026-03-31'고정 기준일 00:00DATE

• 서버와 세션 기준 시각 비교

SELECT TO_CHAR(SYSDATE, 'YYYY-MM-DD HH24:MI:SS') AS "서버 기준",
       TO_CHAR(CURRENT_DATE, 'YYYY-MM-DD HH24:MI:SS') AS "세션 기준",
       SESSIONTIMEZONE AS "세션 시간대"
  FROM dual;
클라우드 리전만으로 표시 시각을 판단하지 않기.
세션 시간대를 바꾸어도 SYSDATE가 같은 방식으로 바뀌는 것은 아님.
업무 기준일과 SQL 실행 시각을 구분.
실습 날짜 계산은 기존 기준일 2026-03-31을 유지.
타임스탬프와 시간대
  • SYSTIMESTAMP는 서버 기준 시각, CURRENT_TIMESTAMP는 세션 시간대 기준 시각. (둘 다 TIMESTAMP WITH TIME ZONE 반환)
  • DBTIMEZONE은 데이터베이스 시간대 설정이며 SYSDATE의 기준 시간대와 같다고 단정하지 않음.
4.6 · 날짜와 기간 계산

날짜와 기간 계산

기본 문법

날짜2 - 날짜1
MONTHS_BETWEEN(날짜2, 날짜1)
ADD_MONTHS(날짜, 개월 수)
LAST_DAY(날짜)
두 DATE의 차이는 일 단위 숫자. 시간 차이가 있으면 소수 포함.
TIMESTAMP 간 차이는 INTERVAL이므로 DATE의 뺄셈 결과와 구분.

기본 문법

MONTHS_BETWEEN(기준일, 개설일)
  • 첫 번째 날짜가 더 늦으면 양수, 더 이르면 음수 반환.
  • 결과에 소수가 나올 수 있으므로 ROUND로 표시 자릿수 조정.

• 기준일 현재 개설 후 경과 개월 수

SELECT account_number, opened_date,
       ROUND(MONTHS_BETWEEN(DATE '2026-03-31', opened_date), 2)
           AS "개설 후 경과 개월 수"
  FROM accounts
ORDER BY opened_date, account_number;
날짜 간 계산값을 소수 둘째 자리까지 반올림한 결과.
이 예제는 해지 계좌도 포함하며 개설일 이후의 경과 기간을 계산.
개월 수를 해석할 때
  • MONTHS_BETWEEN은 Oracle의 날짜 계산 규칙을 따름. 같은 일자이거나 두 날짜가 모두 월말이면 정수, 그 외 소수 부분은 일반적으로 31일 기준으로 계산됨.
  • 반올림한 값을 정확히 완료된 개월 수나 계약상 유지 기간으로 해석하지 않음.

기본 문법

ADD_MONTHS(날짜, 더할 개월 수)
LAST_DAY(날짜)
  • ADD_MONTHS: 날짜에 지정한 개월 수를 더함.
  • LAST_DAY: 해당 날짜가 속한 달의 마지막 날짜 반환.

• 개설일의 12개월 후 날짜 계산

SELECT account_number, opened_date,
       ADD_MONTHS(opened_date, 12) AS "12개월 후 날짜"
  FROM accounts
ORDER BY account_number;
계산상 12개월 후 날짜이며, 상품 계약에 따른 실제 만기일을 뜻하지 않음.

• 개설월의 마지막 날짜 확인

SELECT account_number, opened_date,
       LAST_DAY(opened_date) AS "개설월 말일"
  FROM accounts
ORDER BY account_number;
월말 날짜 계산 시 주의
  • ADD_MONTHS는 입력 날짜가 월말이거나 대상 월에 같은 일자가 없으면 대상 월의 말일로 보정함.
  • 예: ADD_MONTHS(DATE '2026-01-31', 1) → 2026-02-28.
LAST_DAY는 월말 날짜를 구하지만 시각을 반드시 00:00으로 만드는 것은 아님.
일 시작 시각이 필요하면 TRUNC(날짜) 사용. 계산상 날짜와 실제 상품 만기·계약 기준을 구분.
4.7 · 날짜 단위와 표시 형식

날짜 단위와 표시 형식

기본 문법

TRUNC(날짜)
TRUNC(날짜, 'MM')
TO_CHAR(날짜, '출력 날짜 포맷')
TRUNC(날짜): 해당 일 00:00을 DATE로 반환.
TRUNC(날짜, 'MM'): 해당 월 1일 00:00을 DATE로 반환.
TO_CHAR: 날짜를 표시용 문자로 변환.

• 월 시작일과 월 표시 비교

SELECT account_number,
       opened_date,
       TRUNC(opened_date, 'MM') AS "개설월 시작일",
       TO_CHAR(opened_date, 'YYYY-MM') AS "개설월 표시"
  FROM accounts
 ORDER BY account_number;

기본 문법

TO_CHAR(날짜, '원하는 날짜 포맷')

날짜 포맷

  • YYYY: 네 자리 연도.
  • MM: 두 자리 월.
  • DD: 두 자리 일.
  • DY: 요일 약칭. 예: 목.
  • DAY: 요일 전체 이름. 예: 목요일.
  • HH24: 24시간 기준 시각(00~23).
  • MI: 두 자리 분.
  • SS: 두 자리 초.
MM은 월, MI는 분을 의미함.
날짜와 시간 표시 예: YYYY-MM-DD HH24:MI:SS
요일 표시와 언어 설정
  • DY와 DAY의 요일 표시는 날짜 언어 설정에 따라 달라짐. 한국어 요일을 지정하려면 세 번째 인수 사용.
TO_CHAR(opened_date, 'DY', 'NLS_DATE_LANGUAGE=KOREAN')
TO_CHAR(opened_date, 'fmDAY', 'NLS_DATE_LANGUAGE=KOREAN')
  • fmDAY는 요일 이름 뒤의 채움 공백을 제거함.

• 날짜를 연월일 형식으로 표시

SELECT account_number,
       TO_CHAR(opened_date, 'YYYY-MM-DD') AS "개설일자"
  FROM accounts
ORDER BY account_number;
TO_CHAR 결과는 날짜가 아닌 문자.
날짜 조건은 이전 장처럼 작성
WHERE opened_date >= DATE '2022-01-01'
  AND opened_date < DATE '2023-01-01'
  • 표시 형식과 조회 조건을 구분. 연도 조회는 날짜 범위로 표현 가능.
TIMESTAMP의 소수 초 표시
TO_CHAR(transaction_date, 'YYYY-MM-DD HH24:MI:SS.FF3')
  • FF3는 소수 초 세 자리 표시. DATE에는 소수 초가 없으므로 같은 포맷을 그대로 적용하지 않음.
4.8 · 문자를 날짜·숫자로 변환

문자를 날짜·숫자로 변환

변환 방향함수용도
날짜 → 문자TO_CHAR표시 형식 지정
문자 → 날짜TO_DATE입력 날짜 해석
문자 → 타임스탬프TO_TIMESTAMP시각·소수 초 해석
문자 → 숫자TO_NUMBER숫자 문자열을 계산용 숫자로 변환

기본 문법

TO_DATE(문자, '입력 날짜 포맷')
TO_TIMESTAMP(문자, '입력 날짜·시간 포맷')
TO_NUMBER(숫자를 나타내는 문자)

• 입력 문자열을 자료형에 맞게 변환

SELECT TO_DATE('1988/08/18', 'YYYY/MM/DD') AS "날짜 변환",
       TO_TIMESTAMP('2026-10-21 09:30:15.123',
                    'YYYY-MM-DD HH24:MI:SS.FF3') AS "시각 변환",
       TO_NUMBER('12500') AS "숫자 변환"
  FROM dual;
입력 형식과 출력 형식 구분
TO_DATE는 문자열을 날짜로 해석.
화면의 표시 모양은 클라이언트 설정에 따라 달라질 수 있음.
원하는 모양으로 표시하려면 변환된 날짜에 TO_CHAR 적용.
TO_DATE(opened_date, ...)처럼 이미 DATE인 값을 다시 문자 입력 함수에 넣지 않기.
입력 형식을 엄격히 맞추는 FX

• 정상 작동 (완벽히 일치)

-- 정상 작동 (완벽히 일치)
SELECT TO_DATE('1988/08/18', 'FXYYYY/MM/DD')
  FROM dual;

• 에러! (월 앞에 공백 및 한 자리 수 오류)

-- 에러! (월 앞에 공백 및 한 자리 수 오류)
SELECT TO_DATE('1988/ 8/18', 'FXYYYY/MM/DD')
  FROM dual;
숫자 문자열의 소수점·천 단위 구분 문자는 NLS 설정에 영향을 받을 수 있음. 이번 예제는 구분자 없는 정수 문자열로 확인.
4.9 · 연도를 정확하게 해석

연도를 정확하게 해석

생년월일·계약일의 연도는 네 자리로 명확하게 입력.

1988년은 88 대신 1988로 작성.
두 자리 연도는 해석 방식에 따라 다른 세기의 날짜가 될 수 있음.
  • TO_CHAR: 날짜를 원하는 형식의 문자로 표시.
  • TO_DATE: 문자를 지정한 형식으로 해석하여 날짜로 변환.

네 자리 연도로 날짜 지정

TO_DATE('1988/08/18', 'YYYY/MM/DD')

1988년 8월 18일을 의미함.

보충: 두 자리 연도의 해석 · YY·RR·YYYY·RRRR

기본 문법

TO_DATE(문자, '입력 날짜 포맷')
TO_CHAR(날짜, '출력 날짜 포맷')
  • TO_DATE: 문자를 지정한 형식으로 해석하여 날짜로 변환.
  • TO_CHAR: 날짜를 지정한 형식의 문자로 표시.
형식TO_CHAR · 날짜 출력TO_DATE · 문자 해석

YYYY네 자리 연도입력한 연도를 사용

두 자리 입력은 RR 규칙 적용

• 같은 생년월일 문자를 네 가지 형식으로 해석

SELECT
    TO_CHAR(TO_DATE('88/08/18', 'YY/MM/DD'),
            'YYYY-MM-DD') AS "YY 해석",
    TO_CHAR(TO_DATE('88/08/18', 'RR/MM/DD'),
            'YYYY-MM-DD') AS "RR 해석",
    TO_CHAR(TO_DATE('88/08/18', 'YYYY/MM/DD'),
            'YYYY-MM-DD') AS "YYYY 해석",
    TO_CHAR(TO_DATE('88/08/18', 'RRRR/MM/DD'),
            'YYYY-MM-DD') AS "RRRR 해석"
  FROM dual;
  • 현재 연도 2026년 기준: YY는 2088년, RR은 1988년으로 해석.
  • YYYY는 0088년, RRRR은 RR 규칙에 따라 1988년으로 해석.
  • 안쪽 TO_DATE로 날짜 변환 후, 바깥 TO_CHAR로 연도를 네 자리로 표시.

RR이 항상 1900년대로 변환하는 것은 아님.

4.10 · NULL 대체와 자료형

NULL 대체와 자료형

기본 문법

NVL(확인할 값, NULL일 때 표시할 값)
  • 값이 있으면 원래 값 반환.
  • NULL이면 지정한 대체값 반환.
  • 확인할 값과 NULL일 때 표시할 값의 자료형을 맞춰 사용.

• 미등록 연락처를 안내 문구로 표시

SELECT customer_id, customer_name,
       NVL(phone_number, '미등록') AS "연락처"
  FROM customers
ORDER BY customer_id;
연락처가 NULL인 고객만 미등록으로 표시.

기본 문법

NVL(숫자컬럼, 0)
NVL(문자컬럼, '미등록')
NVL이 자동 형 변환을 수행할 수 있어도 입력값과 대체값의 자료형을 맞추어 작성.
숫자 컬럼에 NVL(balance, '미등록')처럼 문자를 섞지 않기.
숫자를 안내 문구와 함께 표시하려면 먼저 표시용 문자로 변환.
계산용 숫자와 표시용 문자를 구분.
NULL을 0으로 대체하기 전에
  • 미확인 값과 실제 0은 의미가 다름. 업무 기준이 허용할 때만 0으로 대체.
  • WHERE의 NULL 비교는 Chapter 3, 집계 시 NULL의 처리는 Chapter 5에서 연결.
4.11 · 오류 해결·업무형 실습

오류 해결·업무형 실습

문제와 결과를 비교하여 SQL을 작성하세요. 입력 자료형과 반환 자료형도 설명하세요.

실습 1. 계좌번호 일부 표시

계좌번호와 마지막 6글자를 조회하세요. 마지막 6글자의 제목은 계좌번호 끝 6자리로 지정하고 계좌번호 오름차순으로 정렬하세요.

실습 2. 문자 정리 비교

문자열 ' iM뱅크 '의 양끝 공백을 제거하고, '506-12-000001'의 하이픈을 제거하여 한 행으로 조회하세요. 제목은 양끝 공백 제거, 하이픈 제거로 지정하세요.

실습 3. 대출원금 단위 변환

대출번호·대출원금을 조회하고 대출원금을 억원 단위로 변환하여 소수 첫째 자리까지 반올림하세요. 계산 결과 제목은 대출원금(억원)으로 지정하고 대출번호 오름차순으로 정렬하세요.

실습 4. 고정 기준일의 경과 개월 수

정상 상태 계좌의 계좌번호·개설일자와 2026년 3월 31일 기준 경과 개월 수를 조회하세요. 소수 둘째 자리까지 반올림하고 제목은 경과 개월 수로 지정하세요. 경과 개월 수 내림차순, 계좌번호 오름차순으로 정렬하세요.

실습 5. 개설월 계산과 표시

계좌번호·개설일자·개설월 시작일·개설월 표시를 순서대로 조회하세요. 월 시작일은 DATE로, 월 표시는 YYYY-MM 형식의 문자로 반환하고 계좌번호 오름차순으로 정렬하세요.

실습 6. 날짜 변환 오류 수정

문자 1988/08/18을 날짜로 변환한 뒤 1988-08-18 형식의 문자로 표시하려는 SQL입니다. 입력·출력 포맷을 수정하세요.

SELECT TO_CHAR(TO_DATE('1988/08/18', 'YYYY-MM-DD'),
               'YYYY-MI-DD') AS "생년월일"
  FROM dual;
Oracle은 FX 없이 구분자가 다른 일부 입력도 허용할 수 있음. 실행 여부만 보지 말고 입력 포맷의 의미와 MM·MI를 확인.
